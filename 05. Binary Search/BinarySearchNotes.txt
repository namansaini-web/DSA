BINARY SEARCH 

1. What is Binary Search?
Binary Search is a searching algorithm used to find an element in a sorted array.
It works by repeatedly checking the middle element and eliminating half of the search space.

2. Important Condition
The array must be sorted before applying Binary Search.

3. Main Variables
• low → starting index of the search range
• high → ending index of the search range
• mid → middle index of the search range
• target → element we want to find

4. How Binary Search Works
Step 1: Find the middle element.
Step 2: Compare the middle element with the target.
Step 3:
  • If middle == target → element is found.
  • If middle < target → search the right half.
  • If middle > target → search the left half.
Step 4: Repeat until the element is found or the search range becomes empty.

7. Time Complexity
Best Case: O(1)
Worst Case: O(log n)
Average Case: O(log n)

8. Space Complexity
Iterative Binary Search: O(1)

9. Binary Search vs Linear Search
Linear Search checks elements one by one → O(n)
Binary Search eliminates half of the elements at each step → O(log n)

10. Remember
• Array must be sorted.
• Always check the middle element.
• Smaller target → move left.
• Larger target → move right.
• Each step removes about half of the remaining elements.
